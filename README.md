# CSV Lab

Σύντομη περιγραφή: εφαρμογή Tkinter για επεξεργασία εργαστηριακών Excel και παραγωγή τελικού CSV με zero calibration blocks.

## Βασικά
- Entry point εφαρμογής: `python csv_Lab.py`
- Κεντρικές ρυθμίσεις: `config.py`
- Pipeline modules: `modules/`
- GUI components: `gui/`

## Αναλυτική τεκμηρίωση
Για πλήρη και οργανωμένη τεκμηρίωση αρχιτεκτονικής, ροών και εντοπισμένων λαθών/απροσεξιών, δες:

- **`DOCUMENTATION.md`**

## Γρήγορη εκτέλεση
```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python csv_Lab.py
```
